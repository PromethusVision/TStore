## Qualification rule

The canonical variable-depth contract permits an L2 node to be terminal. A
future expansion example or a `READY_FOR_L3_L4` note is not an existing
canonical child. Therefore a normal, professional-review-free owner-final L2
with no materialized child is a `LEAF_ASSIGNABLE_CANDIDATE` unless the canonical
sources contain contrary structural evidence.

`LEAF_ASSIGNABLE_CANDIDATE` is only structural qualification. Every Wave 36A
category import row remains `lifecycle_state=staged`, `is_active=FALSE` and
`is_assignable=FALSE`; public visibility and pilot activation remain separate
authorized changes.
