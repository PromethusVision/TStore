# Gamification Notification Model

Status: **PROPOSED — OWNER/PRIVACY REVIEW REQUIRED**
Wave: 18 / Workstream AX

## Candidate events

Badge earned/activated, factual badge expiry/revalidation, correction/revocation, challenge completion if approved and dispute outcome.

## Rules

- Notifications are optional/informational except security/policy-required account messages.
- No shame, social comparison, purchase pressure or “streak kaybedeceksin”.
- Do not reveal sensitive purchase/category/merchant detail on lock screen.
- One source event creates one deduplicated notification; channel retry does not duplicate state.
- Deep link rechecks auth/privacy/current lifecycle.
- Retired/held/reversed state uses neutral and explainable language.

## Frequency

Bundle low-priority achievements; quiet hours and customer controls. “Near badge” reminders are disabled by default if progress requires spending.
