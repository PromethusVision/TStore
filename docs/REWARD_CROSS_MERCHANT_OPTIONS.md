# Reward Cross-Merchant Options

**State:** P0 OWNER DECISION REQUIRED

## Options

| Option | Earning / redemption | Benefit | Risk |
|---|---|---|---|
| A — Merchant-specific | Earn and redeem with the same program owner/shop scope | Clear liability and local loyalty | Fragmented balances; branch rules needed. |
| B — Platform-wide | Earn at A, redeem at B | Simple customer story | Platform liability, clearing, free-rider and policy complexity. |
| C — Hybrid | Merchant value plus separately funded platform campaigns | Flexible | Two ledgers/rules; highest comprehension burden. |

## Recommendation

If Reward proceeds after the pilot, start merchant-specific with centrally governed immutable terms and explicit shop/merchant scope. Do not imply transferability. Platform-wide or hybrid value requires funding, settlement, accounting/legal and dispute decisions first.

Cross-merchant scope never changes review rights, merchant reputation or sponsored ranking.
