## Method interpretation

- Wilson/lower-bound methods estimate a **binary** success proportion. Mapping 1–5 answers to
  “positive/not positive” discards ordinal information and needs an explicit threshold.
- Bayesian shrinkage can reduce two-perfect-ratings distortion, but the prior and grouping policy
  can encode unfairness. A prior learned from a tiny or heterogeneous merchant set is unreliable.
- Five response points remain a defensible mobile compromise because the product already uses star
  language and the structured flow must stay fast; this is a product hypothesis, not a research fact.
- Time variation supports showing the evidence window. It does not prove that every old response
  should be mechanically discounted.
