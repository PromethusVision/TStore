# Customer Badge Surface Options

**State:** OPTIONS — NO UI IMPLEMENTATION

| Surface | Default privacy | Recommendation |
|---|---|---|
| Private profile | Private | Best initial candidate; explanation and controls. |
| Activity/history | Private | Show evidence summary without sensitive purchase detail. |
| Review byline | Public/other customers | Defer; only non-sensitive badge with explicit meaning/choice. |
| Home/banner | Private | Avoid pressure and clutter; optional milestone notice only. |
| Leaderboard | Public | Exclude; creates social rank/spend disclosure. |

Customer chooses public display where offered. Revoked/retired badges are not silently relabeled; support history remains private. No badge implies wealth, moral worth or review reliability beyond its stated evidence.
