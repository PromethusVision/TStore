# Algorithm Simplification Review

**State:** LEAN RECOMMENDATION — OWNER REVIEW REQUIRED

## Simplifications retained

- One visible flow, but only two logical outputs: existing product review and structured shop evaluation.
- Three leading questions; four-question experiment only if the overall response adds measurable value.
- Labeled 1–5 scale; no adaptive sector survey, sentiment scoring or mandatory answers in V1.
- Raw per-purchase evidence but one effective customer+shop contribution per selected window.
- Shop-first scope; no organization roll-up, public merchant star or badge-driven rank in V1.
- Model A remains the transparent audit baseline; Model B + D is evaluated offline before publication.
- No pilot time decay; keep timestamps and introduce a disclosed window only when longitudinal evidence exists.
- Three narrow primary badge hypotheses; composite and meta graphs stay dormant.
- Rules recompute deterministically; human cases address evidence/disputes, not routine arithmetic.

## Complexity intentionally preserved

Immutable origin attribution, idempotency, question/algorithm versioning, customer caps, lifecycle states,
fraud holds, appeals and audit history prevent irreversible ambiguity. Removing them would make later runtime
safer neither for customers nor merchants.

## Rejected complexity

Opaque weighted composite scores, arbitrary 100% certainty, exponential decay at launch, organization-wide
badge copying, per-sector formulas, customer GPS-based locality, manual rating edits and automatic punitive
fraud scores.
