# EsnaftaVar Esenler Pilot — Catalog Bootstrap Model

**State:** `PROPOSED WORKFLOW — NO DATA OR SCHEMA CHANGE`

## Goal

Create enough truthful, reusable product identity and shop-listing depth for the
selected cell without pretending the full taxonomy/catalog is complete.

## Bootstrap order

1. freeze pilot allowlist and promised ordinary domains;
2. inventory target merchants and representative products;
3. search/reuse existing canonical product and variant identities first;
4. attach merchant-owned listing facts: shop, price, availability, SKU and time;
5. capture unmatched goods as provenance-bearing candidates;
6. review match/create/reject/request-more outcomes;
7. publish only approved products with active truthful listings;
8. run duplicate, policy, media, search-task and freshness sampling;
9. preserve correction/merge/split lineage; never overwrite history invisibly;
10. measure queue burden before adding shops/domains.

## Ownership boundary

| Fact | Owner |
|---|---|
| Product identity/name/brand/model/taxonomy/variant facts | Canonical catalog workflow |
| Shop price/availability/merchant SKU/freshness | Exact shop listing |
| Candidate observation/photo/barcode/source | Candidate/evidence workflow |
| Search aliases/facets | Governed taxonomy/facet contract |
| Verified purchase snapshot | Server-authoritative transaction fact |

## Bootstrap modes

| Mode | Use | Risk |
|---|---|---|
| Curated reusable core | Common products across several shops | Lowest queue load; can miss local specificity |
| Merchant-assisted capture | Shop-specific useful assortment | Labor intensive; evidence consistency needed |
| Merchant self-service | Mature repeatable matching/listing | Unsafe before tooling/authority gates |
| Bulk import | Not a default pilot shortcut | Duplicate, provenance, policy and stale-data risk |

## Queue capacity rule

New merchant acquisition pauses when candidate age, unresolved duplicate/policy
cases or sampling failures exceed the operator's approved capacity. Do not turn
candidate backlog into public supply to protect launch dates.
