# Turkish Localization Test Model

State: PROPOSED — OWNER REVIEW REQUIRED

Turkish is the primary customer language and requires semantic as well as visual QA.

## Coverage

- dotted/dotless I casing and diacritics;
- singular/plural, punctuation, apostrophes, dates/times, currency, decimals, units, and phone/address formats;
- canonical taxonomy names, aliases, search normalization, and no ASCII-only identity derivation;
- Auth/recovery, permissions, errors, policy/rejection, support, and store copy;
- truncation at text scale and narrow devices;
- user-entered Unicode normalization without destructive rewriting.

Snapshots/goldens do not prove language quality. A native Turkish review of release-critical copy remains manual. Technical error codes stay stable while user text is localized.
