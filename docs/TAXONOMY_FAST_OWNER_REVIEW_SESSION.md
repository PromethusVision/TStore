# Taxonomy Fast Product Owner Review Session

## Status

**PRACTICAL REVIEW SCRIPT — NOT A MEETING TRANSCRIPT / NO DECISIONS RECORDED / NOT CANONICAL**

This script lets the Product Owner decide reusable boundaries before touching domain lists. It is designed for approximately **75–110 minutes** of owner time plus asynchronous legal/compliance follow-up. The owner should use the root decision cards as the answer sheet; this document does not preselect or finalize any choice.

## Before the session

Prepare only these four views:

1. `TAXONOMY_OWNER_DECISION_CARDS.md` — answer sheet.
2. `TAXONOMY_ROOT_DECISION_RECOMMENDATIONS.md` — rationale/tradeoffs.
3. `TAXONOMY_ROOT_POLICY_EVIDENCE_REFRESH.md` — official-source limits.
4. `TAXONOMY_L2_BULK_APPROVAL_CANDIDATES.md` — domain grouping.

Do not present 224 L2 rows at the start. Do not treat silence, meeting attendance or the recommended default as approval.
