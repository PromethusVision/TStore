# EsnaftaVar Esenler Pilot — Ads, Reward and Reputation Timing Review

**State:** `CONTRARIAN RECOMMENDATION — NOT OWNER FINAL`

## Comparative test

| Pilot mode | Core learning quality | Added dependencies | Distortion/risk | Recommendation |
|---|---|---|---|---|
| Organic + commercial-offer hypothesis | Highest: discovery, truth and natural repeat use remain visible | Merchant offer, acquisition and support | Monetization still unproven | Preferred first controlled pilot |
| Ads-enabled | Paid visibility/business model can be tested | Sponsored object, disclosure, ranking, policy, billing, fraud, reporting, privacy, support | Can hide weak organic value and overload ops | Post-stabilization, narrow separate experiment |
| Reward/Gamification-enabled | Incentive response can be tested | Funding, ledger, accounting, fraud, reversals, support, dark-pattern review | Subsidized behavior masks product value | Defer; shadow concepts only later |

## Ads entry gates

Organic ranking/relevance stable; useful listing density; current policy allowlist;
merchant tool/reporting; textual `Sponsorlu` disclosure acceptance; invalid-traffic,
budget/ledger/reconciliation, dispute, privacy and kill-switch readiness; explicit
owner decision. Otherwise remain organic-only.

## Reward/Gamification entry gates

Stable authoritative QR facts and reversals; funding/liability/unit/redemption/
expiry decisions; legal/accounting/privacy review; immutable ledger/idempotency;
fraud/appeal/support; clear customer value without spending pressure. Generic
analytics can never reconstruct reward value.

## Reputation timing

Keep existing rating/count independent. Do not launch a composite score or badge
until enough shop-scoped history, evidence freshness, new-merchant fairness,
explanation, revocation and appeal exist. Paid activity and reward participation
never create reputation evidence.

## Verdict

Delaying all three systems improves the probability that the first pilot measures
the core local-discovery and merchant-truth proposition. This is an agent
recommendation; Product Owner has selected no timing option.
