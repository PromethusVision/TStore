# EsnaftaVar Esenler Pilot — Customer Retention and Engagement

**State:** `OPTIONS — NO TARGET FINALIZED`

Customer retention is repeated useful local discovery in an eligible cohort, not
notification opens, reward-funded behavior or raw sessions.

## Candidate measures

- return to a launch cell within a declared window;
- repeated qualified discovery task;
- distinct useful shop/product exploration;
- directions/contact intent with honest caveats;
- verified-purchase participation and coverage, where enabled;
- voluntary feedback and problem resolution;
- release/environment-qualified active customer count.

## Engagement levers for first pilot

- better supply truth and local relevance;
- merchant/customer education at physical shops;
- useful saved items/cart intent already in product;
- carefully scoped operational notifications already supported;
- explicit “new/updated nearby supply” only when truthful and consented.

Do not use economic rewards, streaks, leaderboards, artificial scarcity, excessive
push or paid reputation to manufacture retention. If core usefulness does not
repeat, pause and repair density/search/truth before adding mechanics.
