# Accessibility Test Model

State: PROPOSED — OWNER REVIEW REQUIRED

## Automated and manual coverage

- semantic labels, roles, states, focus order, touch targets, and contrast;
- text scale, bold text, display size, orientation, and keyboard navigation where applicable;
- screen reader on representative Android/iOS flows;
- error/loading/success announcements and non-color-only meaning;
- modal, snackbar, camera/QR, permission, and deep-link focus behavior;
- reduced motion and timeout extensions where needed.

Automated semantics/widget checks catch regressions but cannot certify human usability. Manual acceptance covers auth, discovery/search/product, cart/review, location, QR, and future merchant critical paths using the exact artifact.
