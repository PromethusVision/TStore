# EsnaftaVar Cohort Model

**State:** `PROPOSED MINIMAL OPTIONS`

Use cohorts only when they answer a pilot decision and have enough volume. Safe
candidate cohorts include activation week, first verified-purchase week, merchant
catalog-ready week, app release and approved broad taxonomy/sector group.

Avoid cohorts by precise location, raw search, sensitive attributes, private case,
small merchant/customer group or inferred demographic. Apply minimum cohort size,
fixed eligibility, consistent window and test/demo/bot exclusion.

Start with weekly aggregate merchant/shop and verified-purchase cohorts. Customer
longitudinal cohorts wait for identity/privacy decision. Do not build arbitrary
multi-dimensional slices that invite re-identification or false conclusions.
