# Internal Response Target Options

**State:** OPTIONS — NOT A CONTRACTUAL SLA

## Purpose

Internal targets help triage and staffing. They do not promise a legal/customer deadline, guaranteed resolution, or lower evidence standard.

| Priority | Candidate acknowledgement posture | Candidate action posture |
|---|---|---|
| P0 | immediate operational acknowledgement | containment as soon as safely possible; continuous ownership |
| P1 | rapid same operating period | bounded investigation/containment target |
| P2 | normal queue target | evidence-based resolution by case type |
| P3 | backlog/service target | batch/periodic handling |

No exact hours/days are finalized.

## Clock distinctions

- intake-to-acknowledgement;
- triage time;
- operator active-review time;
- waiting-external time;
- decision time;
- communication/appeal time;
- incident containment/recovery time.

Pause only the relevant internal clock when waiting externally; never hide total age. Statutory or contractual obligations are recorded separately and can override internal targets after responsible review.

## Target design inputs

Harm, reversibility, feature exposure, queue volume/mix, staffing hours, evidence availability, external authority/vendor dependency, vulnerable users, and false-positive risk.

## Anti-gaming

Do not downgrade priority to protect metrics, close/reopen to reset age, pressure operators toward low-quality decisions, or count automated acknowledgements as resolution. Report distribution and exceptions, not one flattering average.
