# Terms and Support Release Dependency

**State:** RELEASE DEPENDENCY — NOT LEGAL ADVICE

Commercial release needs reachable, consistent customer-facing:

- terms/service conditions appropriate to enabled features;
- support contact/channel and expected identity-verification method;
- account deletion/correction route;
- merchant/support escalation if Merchant App participates;
- policy/report/appeal routes for reviews, listings and user content;
- app/store links that remain available without login where appropriate.

QA checks link availability, environment correctness, Turkish copy, deep-link/browser behavior and consistency with actual support capacity. Support must never request passwords or expose internal abuse signals.

OWNER_DECISION_REQUIRED: approve legal documents through qualified review and select staffed support channels/ownership.
