## Module gates

- **Ads:** sponsor disclosure → contextual eligibility → claim proof → measurement minimization.
- **Rewards:** legal/payment perimeter → accounting/tax → terms/expiry → authoritative ledger.
- **Regulated products:** item rule → merchant capability/evidence → listing → ad/reward eligibility.
- **Chat/media:** purpose/access → report/evidence → retention/deletion → operator safeguards.

No step authorizes Production mutation. Implementation belongs to later, separately authorized waves.
