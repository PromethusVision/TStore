# Reward Platform Governance

Status: **PROPOSED — OWNER/LEGAL/FINANCE/SECURITY REVIEW REQUIRED**
Wave: 18 / Workstream AK

## Platform responsibilities

- Define eligible program templates, units, funding proof and policy allowlist.
- Version terms, earning/redemption/correction/expiry behavior.
- Authorize merchant/program activation and suspension.
- Protect immutable ledger/idempotency and monitor fraud/anomalies.
- Provide customer/merchant explanation, dispute and appeal runbooks.
- Establish liability, retention, accounting/tax and privacy ownership.
- Prevent paid ads/reputation/reviews from influencing eligibility.

## Change governance

Rule changes are future-effective unless an explicit corrective/legal rule applies. Every earn event retains the applicable rule/terms version. Emergency suspension stops new earnings/redemptions only under defined customer-protection behavior; it does not erase history.

## Operational roles

Product Owner selects root product/economic options; policy/legal reviews restricted domains/terms; finance/accounting validates liability; security owns abuse controls; support handles evidence-linked disputes. These roles are conceptual, not permissions implementation.
