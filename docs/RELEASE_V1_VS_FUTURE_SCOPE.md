# Release V1 vs Future Scope

**State:** PROPOSED

## MUST V1

- immutable version/build/commit/environment/artifact hash;
- external fail-closed signing and correct `com.esnaftavar.app` identity;
- feature freeze, exact artifact clean/upgrade/physical acceptance;
- Auth/deep-link/location/cart-review/QR release gates;
- migration/backend compatibility and containment;
- explicit go/no-go, Production authority, support/legal dependency;
- staged track, minimum health monitoring and hotfix path.

## SHOULD V1

- Android internal/closed progression before Production;
- small risk register, release notes/changelog and post-release observation;
- advisory update policy;
- Android-only pilot when owner accepts reach limits.

## DEFER

iOS until signing/TestFlight/device gates are funded, automatic store promotion, broad canary infrastructure, elaborate release branches, forced update except verified safety need, full Merchant App release and enterprise release analytics.

Nothing in DEFER is silently marked PASS.
