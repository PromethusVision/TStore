# Merchant App Review Response Options

Status: **PROPOSED — OWNER_DECISION_REQUIRED**
Wave: 17 / WP46

## Options

| Option | Benefit | Cost/risk |
|---|---|---|
| A — No replies in V1 | Lowest moderation/support risk | Merchant cannot publicly resolve feedback |
| B — One public merchant reply | Useful trust signal | Moderation, notification, edit/delete and abuse rules needed |
| C — Structured private resolution | Reduces public conflict | Customer messaging/privacy/support scope expands |

## Recommendation

Option A for initial pilot; design response extension point but do not ship replies until moderation and anti-retaliation contracts exist.

## If replies are later approved

- One clearly labeled merchant response per active review; edit history/audit.
- Merchant cannot change customer content/rating or review eligibility.
- Reporting and moderation apply to both sides.
- Staff capability, response ownership after staff departure and customer notification must be defined.
- Deleting merchant reply cannot delete review/evidence.
