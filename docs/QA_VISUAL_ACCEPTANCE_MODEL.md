# Visual Acceptance Model

State: PROPOSED — OWNER REVIEW REQUIRED

Visual acceptance combines deterministic screenshots with human review of the exact release candidate.

## Evidence set

- agreed critical screens and loading/empty/error/success states;
- narrow/representative/large displays and text-scale matrix;
- keyboard, focus, safe areas, orientation, permissions, and modals;
- real Turkish copy and representative synthetic content;
- Android and iOS platform rendering;
- accessibility, contrast, image quality, and visual hierarchy.

Screenshot diffs are triage aids, not automatic design truth. Dynamic timestamps/media are controlled or masked. Reviewers record artifact hash, device/OS, scenario, expected design reference, decision, and rationale.

Final UI kit and Product Owner visual approval remain manual open gates. This foundation does not claim them PASS.

OWNER_DECISION_REQUIRED: select canonical devices/screens and visual approver.
