# Merchant-Funded Reward Options

**State:** OPTIONS — OWNER DECISION REQUIRED

| Model | Control | Customer promise | Main risk |
|---|---|---|---|
| Fixed platform template funded by merchant | Merchant opts in; platform fixes rules | Consistent | Merchant margin/comprehension. |
| Merchant chooses from bounded templates | Limited threshold/benefit choices | Moderately consistent | Version proliferation. |
| Fully merchant-defined | Broad control | Inconsistent | Unfair retroactive changes and disputes. |

## Guardrails

- Merchant cannot reduce or cancel already-earned progress/value.
- Program term changes are versioned and prospective with notice.
- Funding/settlement status is checked before issuance; a failed reward does not roll back a verified purchase.
- Platform policy exclusions override merchant configuration.
- Ads spend, reward funding and reputation evidence remain separate.

**Recommendation:** bounded templates only if a post-pilot program is approved; no fully arbitrary configuration.
