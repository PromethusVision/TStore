The proposed tree supports broad representative coverage, but the primary-leaf gate is not yet final-ready: cross-domain accessories, regulated intended use, PPE, fitment, equipment cases, pro-audio, gift bundles and service/digital exclusions need root rules. A small number of root decisions can resolve many rows without rewriting source proposals.
