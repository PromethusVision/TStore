# Merchant Badge Portability

**State:** PROPOSED — OWNER DECISION REQUIRED

| Change | Default recommendation | Reason |
|---|---|---|
| Shop rename | Badge remains with stable shop ID | Cosmetic identity change. |
| Address move, same operating entity | Re-evaluate location/branch evidence | Customer context may materially change. |
| Branch transfer to another merchant | Do not automatically transfer merchant-scoped badge | Ownership/governance changed. |
| Merchant-org rename | Preserve org evidence if legal identity verified | Display name is not identity. |
| Shop merge/split | Retire/supersede and derive new state | Avoid history duplication. |
| Closure/reopen | Preserve audit; re-evaluate freshness | Old evidence may be stale. |
| Sector change | Re-evaluate sector-dependent badge | Evidence meaning may change. |

Badge lineage uses `EARNED/ACTIVE/REVOKED/RETIRED/SUPERSEDED`, never copy-and-delete. Public explanation names scope and current evidence window.
