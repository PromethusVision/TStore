# Android-Only Pilot Review

**State:** PROPOSED — OWNER_DECISION_REQUIRED

## Benefits

- current Windows/Android toolchain and real signing work are closer to completion;
- fewer signing/store/device matrices reduce launch risk and support load;
- faster feedback on core Esenler commerce and physical QR behavior.

## Risks

- excludes iPhone customers/merchants and biases pilot learning;
- later iOS launch still requires callback, permission, layout and backend compatibility work;
- support and public messaging must clearly state platform availability;
- Android manufacturer variation still requires focused physical coverage.

## Recommendation

Use Android-only for the first tightly bounded commercial pilot if owner research accepts reach limitations and all Android signing/exact-artifact/physical/Production gates pass. Do not label iOS ready or silently abandon its architecture.
