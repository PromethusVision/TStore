## Regression map

- Cubit/repository actions, loading/error/empty/success, duplicate-submit guards;
- forms, keyboard/focus, validation, confirmation, and recovery;
- location/camera permissions and lifecycle;
- cart/review/QR eligibility and server authority;
- semantics, text scale, contrast, touch targets, and Turkish copy;
- device sizes, dark/light themes if supported, and image/layout stability.

Use component contracts plus targeted widget/golden/screenshot review. Functional tests are rerun even when a change is presented as visual-only. Manual Product Owner visual acceptance remains open.
